About the Project

AI-Assisted Brain MRI Analysis

BrainScan AI demonstrates how deep learning and explainable AI can assist with brain MRI image analysis.

What is BrainScan AI?

BrainScan AI is a web-based artificial intelligence project that analyzes brain MRI images using a ResNet50 transfer learning model.

The platform can classify images into supported categories and provide visual explanations using Grad-CAM.
